# Notebooks do Projeto

Esta pasta é destinada aos notebooks utilizados no desenvolvimento do sistema de recomendação de receitas sustentáveis.

## Etapas do desenvolvimento

1. Análise exploratória dos dados (EDA).
2. Tratamento e preparação dos dados.
3. Desenvolvimento dos modelos de recomendação.
4. Aplicação do critério de pegada hídrica (WF).
5. Avaliação e comparação dos resultados.

## Técnicas estudadas

- Recomendação por popularidade.
- Filtragem colaborativa.
- Filtragem baseada em conteúdo.
- Recomendação híbrida.
- Filtragem colaborativa com ajuste sustentável.

## Avaliação

Os modelos são avaliados utilizando Precision@10, Recall@10 e a média do indicador WF das receitas recomendadas.

Os notebooks com os códigos e testes serão adicionados a esta pasta.
